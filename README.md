# 6-DOF Robotic Arm CAD Design

## Project Overview

This repository contains the complete CAD design of a **6-DOF (Degrees of Freedom) Robotic Arm** developed using SolidWorks. The project focuses on robotic mechanism design, 3D CAD modeling, assembly creation, and understanding the mechanical structure of an articulated robotic manipulator.

The robotic arm consists of six rotational axes that provide flexibility and precise movement of the end effector. The design demonstrates concepts of robotic joints, mechanical integration, and automation system development.

## Features

- Complete 3D CAD model of a 6-axis robotic arm
- Individual part modeling
- Full assembly design
- Parametric CAD modeling
- Multi-joint robotic mechanism
- Modular mechanical structure
- Design optimized for further development and simulation

## Software Used

- **SolidWorks** - 3D CAD Modeling and Assembly Design

## Project Files

The repository includes:

- SolidWorks Part Files (`.SLDPRT`)
- SolidWorks Assembly Files (`.SLDASM`)
- CAD Images and Rendered Views
- 2D Drawing
